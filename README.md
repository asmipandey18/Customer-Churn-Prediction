# Customer Churn Prediction

## 📌 Project Overview

Customer Churn Prediction is a Machine Learning project that aims to identify customers who are likely to stop using a company's services. This project uses historical customer data and a Logistic Regression model to predict customer churn. A Flask API is developed to serve predictions, while MongoDB is used for database management.

## 🎯 Problem Statement

Customer churn is a major challenge for businesses because losing customers can negatively affect revenue and business growth. Identifying customers who are likely to leave helps companies take preventive actions, improve customer satisfaction, and increase customer retention.

The goal of this project is to build a Machine Learning model that predicts customer churn based on customer information, helping businesses make data-driven decisions and reduce customer loss.

## 🛠️ Technologies Used

- **Python** – Core programming language.
- **Pandas** – Data manipulation and analysis.
- **NumPy** – Numerical computations.
- **Scikit-learn** – Machine Learning model training and evaluation.
- **Logistic Regression** – Classification algorithm for predicting customer churn.
- **Flask** – Building the REST API for serving predictions.
- **MongoDB** – NoSQL database for storing and managing customer data.
- **Pickle** – Saving and loading the trained Machine Learning model.
- **Git & GitHub** – Version control and project hosting.
